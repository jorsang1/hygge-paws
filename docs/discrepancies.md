# Discrepancies: Website vs. Brochures

This document lists the inconsistencies found between the current website content and the information presented in the tri-fold brochures (EN, DK, ES).

---

## 1. Brand Name (English Brochure)

| Source | Value |
|---|---|
| Website | **Hygge Paws** |
| EN brochure | **Quiet Paws Copenhagen** |
| DK brochure | Hygge Paws |
| ES brochure | Hygge Paws |

**Issue:** The English brochure uses a completely different brand name ("Quiet Paws Copenhagen"). This appears to be a template that was not updated with the correct brand. All other materials consistently use "Hygge Paws".

---

## 2. Business Type / Positioning

| Source | Value |
|---|---|
| Website | Dog daycare |
| DK brochure | **Hundeskole** (Dog School) |
| ES brochure | **Escuela de Perros** (Dog School) |

**Issue:** The brochures position the business as a "Dog School", while the website calls it a "dog daycare". These are different service propositions. The website should clarify whether it is a daycare, a school, or both.
